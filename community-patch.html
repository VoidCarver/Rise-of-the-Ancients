Community Patch

The Community Patch is a collection of balance changes including:

- Civilization bonus adjustments, from small tweaks to larger changes
- A new technology and two new units
- Unit stat and technology tweaks
- Small quality-of-life changes
- Reworked tooltips, bug fixes, and more!

You can read the current version patch notes below, as well as all the changes ever made in the Changelogs section.
The changes are based on suggestions and ongoing feedback from Return of Rome players.

How to get the Mod:

Visit the Mod Page to Subscribe

You will need to sign in with your Steam or Xbox account.

The mod can also be found directly in-game by searching for "ROR Community Patch".

Install Instructions:

- Subscribe to the Mod
- Open the in-game "Mods" page
- Verify that Community Patch Mod is above any other Tooltip mods
(such as "14335_Improved Extended Tooltips")

Quick Tips:

- New Tooltips are best viewed with Tooltip Scale set to 50%
(Options > Interface > Tooltip Scale)
(Higher values may reduce tooltip quality; values above 60% are not recommended)

Update Available:

If you are already subscribed, the mod should update automatically upon launching the game.

Currently supported in English only.

The mod will still work if your game is set to another language but with English text.

"Work Factors" (WF) Overhaul on Farm's gathering rates

  • To be clear, we did not add these "Work Factor Adjustments"; they have been present in the game since release. (This overhaul is mandatory since Wheel move speed was changed)
  • What is "WF," you might ask, and why is it here?
    In AoE DE, farmers stand still and farm on the same tile.
    In the AoE2 DE farming cycle, villagers gather a quarter of their carry capacity on each of four randomly chosen tiles.
  • The devs needed to adapt farming to the AoE2 farming mechanic and, at the same time, probably wanted to retain the AoE DE farming balance, so they ended up adding these Work Factors so villager move speed doesn't impact gathering rates, only specific Farming bonuses (Minoans) or Extra Work Rate (Palmyrans) do.
  • Villagers still benefit from being faster the farther away they are from the drop-off location, but not during the farming cycle, just as in AoE DE.
  • A lot of effort was put into these adjustments to make sure everything is working as intended.

AI Support

  • Added unitcategories.json and unitlines.json to the Datamod.
  • Added Horseman and Heavy Camel Rider IDs to unitcategories.json
  • Added Horseman and Heavy Camel Rider-Line IDs to unitlines.json
  • These changes allow AI support for the new units.
    Needlework technology is already supported by the official AI, but the new units require additional code to enable support.
  • AI constants are implemented as follows:
    - Techs
    (defconst ri-needlework 191)
    (defconst ri-horseman 196)
    (defconst ri-heavy-camel-rider 197)
    - Units
    (defconst horseman 546)
    (defconst heavy-camel-rider 330)
    - Unit Lines
    (defconst scout-cavalry-line -296)
    (defconst camel-line -297)
Known Issues
  • We have done everything possible on our end to make the patch as compatible as possible with CA (Capture Age) but due to the fact that CA does not read custom strings, Needlework, Horseman and Heavy Camel Upgrade will not appear as "currently researching", and the new technology and units will not use the correct icons.
  • The official AI only supports Needlework, not the new units. Try "BruteForce" AI by CheeseOnToast if you want an AI that fully supports the Community Patch.
  • Custom hotkeys have not been implemented yet and we are still looking into implementing them in the future.
    We know it's possible but so far it's been buggy and clunky in our last integration tests so for now, we'd rather not add support than cause problems and provide a poor user experience.
